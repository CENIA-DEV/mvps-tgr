# De reglas a machine learning · one-pager

Nota técnica pública de un caso de estudio de scoring de riesgo desarrollado por CENIA
con un organismo fiscalizador del sector público, en el marco del programa Hazlo con IA.

- `index.html`: documento autocontenido (logos embebidos). Se publica con GitHub Pages desde la rama `main`; también puede abrirse directamente en el navegador.
- `assets/`: logos fuente utilizados en el documento.

No contiene datos, reglas, variables reales ni identificación del organismo.
